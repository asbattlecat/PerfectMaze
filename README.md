# PerfectMaze
Генерация идеального лабиринта на основе алгоритма Эллера.

Предоставляемый функционал:
* Генерация идеального лабиринта размером от 2 клеток до желаемого значения;
* Вывод полученного лабиринта в консоль в упрощенном виде с помощью ASCII символов;
* Вывод полученного лабиринта в файл, структура которого выглядит следующим образом:
  * размер m x n (rows x columns)
  * матрица, где 1 - есть правая стенка у клетки, а 0 - нет правой стенки;
  * матрица, где 1 - есть нижняя стенка у клетки, а 0 - нет нижней стенки;
* Поиск пути из любой клетки в любую другую клетку (поиск в глубину);
* Тестирование генерации;
* Тестирование нахождения пути.
